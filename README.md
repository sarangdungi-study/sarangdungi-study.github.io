# 사랑둥이

조카들 수능 공부용 사이트. https://sarangdungi-study.github.io

문제와 개념을 하나의 지도로 묶었어요. 고학년은 실전 문제에서 시작해 막힌 개념으로 내려가고, 저학년은 기초 개념에서 시작해 문제로 올라가요.

## 파일

| 파일             | 하는 일                                                        |
| ---------------- | -------------------------------------------------------------- |
| `index.html`     | 머리 막대, 메뉴, 글꼴                                          |
| `style.css`      | 디자인 토큰과 화면. 세로 = 휴대폰 화면, 가로 = 태블릿 화면     |
| `data.js`        | 과목 · 개념 · 문제                                             |
| `store.js`       | 로그인, 푼 기록, 오답노트, 요청. 구글 시트(Apps Script)에 저장 |
| `app.js`         | 화면: 홈 · 문제 · 문제 하나 · 개념 지도 · 오답노트 · 요청      |
| `apps_script.gs` | 구글 시트에 붙이는 스크립트 (계정 · 기록 · 오답노트 · 요청 탭) |
| `media/`         | 개념 · 풀이 영상                                               |

## 디자인

모눈 공책, 형광펜, 빨간 채점 펜. 라이트는 종이 공책이고 다크는 밤에 켜 둔 태블릿 공책이에요.

- 색은 `style.css` 맨 위 토큰만 써요. 새 색이 필요하면 토큰부터 추가해요.
- 강조는 형광펜 분홍(`--marker`) 하나. 과목 색(`--kor`, `--math`, `--eng`, `--sci`)은 과목 표시에만 써요.
- 글꼴: 본문 Pretendard, 숫자 JetBrains Mono, 손글씨 메모 Nanum Pen Script(짧은 메모에만).
- 이모지와 그라데이션 배경은 쓰지 않아요.
- 문구는 짧게, 조카들한테 말하듯이 써요.

## 작업 규칙

- 확인: `npm run check` (prettier + eslint). 고칠 때: `npm run format`
- 올리기 전: `npm run stamp` (css·js 주소에 버전을 붙여 휴대폰 캐시 문제를 막아요)
- 이름: 식별자는 영어 camelCase, 상수 표는 대문자(`SUBJECTS`, `PROBLEMS`). 주석과 화면 문구는 한국어.
- 문제 id: 과목 머리글자 + 번호. 실전 `m1`, 기초 `m-e1`. 개념 id: `m-tangent`처럼 과목 머리글자 + 영어 이름.
- 숫자 답은 코드로 검산하고 넣어요.
- 커밋: Conventional Commits + 한국어 요약. 예: `feat(math): 미분 단원 추가`, `fix(note): 오답노트 정렬 오류`. 이모지 없음.
- 작성자: 이 저장소의 로컬 git 설정(sarangdungi-study)으로만 커밋해요.

## 요청 처리

1. 아이들이 `요청` 화면에서 종류와 과목을 골라 보내요. 시트 `요청` 탭에 쌓여요.
2. `node ../tools/feedback.mjs`로 읽어요. 수능 공부와 관련된 요청만 처리하고, 나머지는 `보류`로 둬요.
3. 새 문제를 넣고 검산과 화면 검수를 한 뒤 올려요. 끝나면 `set <번호> 반영 "답"`으로 상태를 바꿔요.
