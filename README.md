# 사랑둥이 (수능 공부 사이트)

주소(예정): https://sarangdungi-study.github.io

조카들 수능 공부용 사이트. `index.html`을 브라우저로 열면 바로 돼요.

| 파일 | 하는 일 |
|---|---|
| data.js | 과목·개념·문제. 문제 ↔ 개념이 서로 연결된 지도 |
| store.js | 로그인·푼 기록·오답노트·피드백 저장. `API_URL`이 비면 이 기기에 저장, Apps Script 주소를 넣으면 구글 시트에 저장 |
| app.js | 화면: 홈(두 입구) · 문제(정렬) · 문제 하나(막힌 곳→기초→쉬운 문제→힌트→풀이→흔한 실수) · 개념 지도 · 오답노트 · 요청 |
| media/ | 개념·풀이 영상 |
| apps_script.gs | 구글 시트에 붙일 스크립트 (계정·기록·오답노트·요청 탭) |
| ../tools/feedback.mjs | 요청 읽기·상태 바꾸기·문제별 정답률 (주소와 키는 ../.env, 깃헙에 안 올림) |

## 피드백 → 출제 순환
1. 아이들이 `요청` 화면에서 종류(문제 더 / 풀이 이해 안 됨 / 개념 설명 / 오류)와 과목을 골라 보내요.
2. 구글 시트 `feedback` 탭에 쌓여요.
3. 수능 세션 Claude가 읽고 **수능 공부 관련만** 처리해요. 관련 없는 요청은 '보류'로 두고 처리하지 않아요.
4. 새 문제는 data.js에 넣고, 숫자는 코드로 검산하고, 화면을 검수한 뒤 올려요. 처리가 끝난 요청은 상태를 '반영'으로 바꿔요.
